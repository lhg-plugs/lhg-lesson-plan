# /lhg-lesson-plan:activity —— 课堂活动设计

用户输入在 `$ARGUMENTS` 中：`"课程主题或教案文件" [活动类型]`。活动类型可选：实验 / 探究 / 讨论 / 辩论 / 游戏 / 角色扮演 / 项目，不指定则按目标层级自动推荐。

## 流程（加载 lhg-lp-activity 全程指导）

### 1. 读目标定活动

1. 如果给了教案文件，先读它的教学目标与知识点清单。
2. 按 `lhg-lp-activity` 第 3 步"目标—活动匹配表"选活动类型：
   - 识记/理解 → 问答、配对游戏、概念图
   - 应用 → 实验、案例分析、情境任务
   - 分析/评价 → 辩论、小组探究、互评
   - 创造 → 项目式任务、设计挑战
3. 高阶目标（应用及以上）**必须**配高阶活动，只讲授不许过关。

### 2. 写活动方案

每个活动按 `lhg-lp-activity` 第 4 步模板输出：

- 活动名称 / 对应目标 / 时长
- 分组方式（几人一组、怎么分组、角色分工）
- 教师指令话术（逐字稿，小白老师能直接念）
- 学生产出物（写什么、画什么、说什么，明确可检查）
- 收束方式（时间到点怎么收：倒计时话术 + 成果抽查 + 点评）

### 3. 现实性检查

按 `lhg-lp-activity` 第 5 步过一遍：教具能不能 5 分钟备齐？分组会不会乱？时间超了砍哪一步？过不了的活动打回重设计。

## 硬规则

- 活动没有"收束方式" → 不许交付（课堂最怕收不回来）。
- 指令话术写"组织学生讨论"这种空话 → 改成逐字稿。
- 实验类活动不写安全/纪律提示 → 打回。
